Smart-App-MVP
Mijn Smart App Python project


Projectbeschrijving

Voor dit project heb ik een Smart App Store ontwikkeld in Python. Via een keuzemenu kan de gebruiker verschillende applicaties openen.

Weerstation

Met het weerstation kunnen actuele weergegevens van verschillende steden worden opgehaald. Hiervoor wordt gebruikgemaakt van de Open-Meteo API.

Smart Home Controller

Met deze applicatie kan een virtuele lamp worden aan- en uitgezet. De status wordt opgeslagen in een JSON-bestand, zodat deze na het afsluiten behouden blijft.

Technische uitwerking

Tijdens het ontwikkelen zijn verschillende programmeertechnieken toegepast, waaronder functies, keuzestructuren, herhalingen, foutafhandeling en het lezen en schrijven van bestanden.

Het proces
Het project is stapsgewijs opgebouwd. Eerst is het hoofdmenu ontwikkeld, waarna de afzonderlijke applicaties zijn toegevoegd en getest.
ChatGPT is gebruikt als ondersteuning bij de codeontwikkeling en het oplossen van programmeervraagstukken.
